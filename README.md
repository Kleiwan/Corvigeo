# FloraWeb

**Sistema de Gestão e Identificação de Mudas e Plantas do Viveiro do IFRN**

## Sobre o projeto

O **FloraWeb** é um sistema desenvolvido para auxiliar no gerenciamento e na identificação das mudas e plantas do viveiro do Instituto Federal do Rio Grande do Norte (IFRN).

O projeto tem como finalidade contribuir com o processo de arborização realizado pelo viveiro, facilitando o manejo das plantas e melhorando a organização das informações. Além disso, busca apoiar iniciativas que proporcionem benefícios à população, como melhoria da qualidade do ar, disponibilização de áreas com sombra, combate às mudanças climáticas e redução dos impactos do calor extremo.

O sistema busca facilitar:

- Organização das espécies;
- Controle das informações;
- Identificação das plantas;
- Gerenciamento do viveiro.

## Problema identificado

Atualmente, o viveiro enfrenta algumas dificuldades relacionadas à organização e ao gerenciamento das mudas e plantas, principalmente:

- Identificação das espécies;
- Organização das informações;
- Gerenciamento das mudas;
- Controle dos registros.

Essas dificuldades podem comprometer a eficiência das atividades realizadas pelos responsáveis pelo viveiro.

## Objetivos do projeto

### Objetivo geral

Desenvolver um sistema digital para melhorar a gestão e a identificação das mudas e plantas do viveiro do IFRN.

### Objetivos específicos

- Permitir o cadastro de mudas e espécies;
- Facilitar a pesquisa de informações;
- Melhorar a organização dos dados;
- Possibilitar a geração de relatórios;
- Permitir o acesso por dispositivos móveis.

## Público-alvo

O sistema será direcionado principalmente a:

- Responsáveis pelo viveiro;
- Bolsistas;
- Servidores;
- Alunos envolvidos nas atividades do viveiro.

## Levantamento de requisitos

Para identificar as necessidades do projeto e definir suas principais funcionalidades, foram utilizados métodos de levantamento de requisitos.

### Métodos utilizados

**Brainstorming**

Utilizado para reunir ideias e identificar funcionalidades que poderiam contribuir para a solução dos problemas encontrados no viveiro.

Entre as ideias levantadas estão:

- Cadastro de mudas;
- Identificação de espécies;
- Sistema de login;
- Pesquisa de plantas;
- Relatórios automáticos;
- Painel administrativo;
- Histórico de movimentações;
- Notificações automáticas.

**Análise de softwares similares**

Foram analisadas ferramentas existentes para identificar funcionalidades e características que poderiam servir de referência para o desenvolvimento do FloraWeb.

### Softwares analisados

| Software | Características observadas |
|---|---|
| PlantNet | Identificação de espécies e pesquisa rápida. |
| iNaturalist | Armazenamento de informações e histórico de registros. |
| BibBlio | Novidades no sistema e e-books. |

### Métodos futuros

Para aprofundar o entendimento das necessidades dos usuários, pretende-se utilizar outros métodos de levantamento de requisitos, como:

- Questionários;
- Entrevistas.

Esses métodos poderão ajudar a compreender melhor as necessidades específicas do público-alvo.

## Benefícios esperados

Com a implementação do FloraWeb, espera-se alcançar:

- Melhor organização do viveiro;
- Identificação mais rápida das espécies;
- Redução de erros nos registros;
- Facilidade no gerenciamento;
- Acesso rápido às informações;
- Modernização do controle das mudas.

## Conclusão

O FloraWeb foi idealizado para solucionar dificuldades encontradas no gerenciamento do viveiro do IFRN.

A partir do levantamento de requisitos, foi possível identificar as principais necessidades dos usuários e definir funcionalidades importantes para o sistema.

Dessa forma, o projeto busca contribuir para a modernização das atividades do viveiro, proporcionando maior organização, facilidade de gerenciamento e eficiência no controle das mudas e plantas.
